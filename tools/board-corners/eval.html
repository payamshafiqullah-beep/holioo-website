Board detector — label and evaluate real photos

1. Label a few hundred classroom photos (click the 4 corners of the board; N = no board in the picture), save labels.json. 2. Evaluate runs the app's detector (pwa/features/scan-detect.js, same code as in the camera) on those photos and reports how many outlines overlap the true board by at least 90 % (IoU), how reliable the confidence score is, and how many empty pictures get a false board. Serve the repository root (npx http-server .) and open /tools/board-corners/eval.html. The same labels.json trains the model (train.py).
